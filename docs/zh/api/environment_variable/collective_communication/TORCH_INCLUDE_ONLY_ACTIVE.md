# TORCH\_INCLUDE\_ONLY\_ACTIVE

## 功能描述

当使用HCCL作为通信后端时，通过此环境变量可控制监控、管道和WatchDog异常出口额外转储是否仅包含尚未观测到完成的FR通信条目。

- 0：输出缓冲区中的全部可用条目。
- 1：过滤已观测到完成的条目，仅保留活动条目。

默认值：0。

> [!NOTE]
>
> 开启过滤后，如果所有通信均已完成，转储中的`entries`可能为空。该情况不表示FR未开启或文件生成失败。

## 配置示例

```bash
export TORCH_INCLUDE_ONLY_ACTIVE=1
```

## 使用约束

- 在相应转储请求处理时读取，建议在启动训练进程前设置。
- 该变量不停止记录，也不删除缓冲区中的已完成条目，只影响本次转储的输出。
- 过滤依据是记录器观测到的设备完成状态，不能单独据此判断通信故障原因。
- 离线匹配需要上下文，排查操作顺序和跨rank不匹配时建议保留默认值0，避免过滤掉已完成的对应操作。
- Python手动导出接口通过`onlyActive`参数控制过滤，不自动使用该变量替代参数默认值。
