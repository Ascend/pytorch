# 方式四：镜像安装

您可以通过拉取预集成PyTorch和TorchNPU的Docker镜像，快速运行环境，免去手动安装依赖的步骤。具体请参考[快速安装](https://www.hiascend.com/developer/software/ai-frameworks/pytorch/download?versionId=182&ids=89dda9ba9de741349efa03687a487678%2C202%2C107%2C1%2C6%2C181%2Cd806)。

> [!NOTE]
>
> - 镜像安装方式仅支持Python 3.12版本。
> - 镜像中预安装了ppyaml、numpy、attrs、decorator、psutil、scipy、jinja2和MarkupSafe等依赖包，以支持相关功能的运行。
