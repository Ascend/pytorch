# Method 1: Offline Installation (.whl)

You can use the `wget` command to download the .whl installation packages of PyTorch and TorchNPU, and then use the pip tool to install PyTorch and TorchNPU.

Before running the installation commands, see [Pre-installation Preparation](preparing_installation.md) to complete the environment variable configuration and other environment preparations.

## Querying Versions

Run the following commands to check the versions of the installed Python, PyTorch framework, and TorchNPU installation packages.

- Check the installed Python version.

    ```bash
    python --version
    ```

    The output shows the Python version as follows.

    ```text
    Python 3.13.0
    ```

- Check the versions of the installed PyTorch framework and TorchNPU installation packages.

    ```bash
    pip list | grep torch
    ```

    The output shows the versions of the PyTorch framework and TorchNPU installation packages as follows.

    ```text
    torch     2.12.0+cpu
    torch_npu      2.12.0
    ```

    > [!NOTE]
    >
    > Because each TorchNPU version is released with installation packages for multiple PyTorch versions, the package version numbers and the TorchNPU version number follow different naming rules. To query the version correspondence, click [Related Product Version Compatibility](https://gitcode.com/Ascend/pytorch/blob/master/COMPATIBILITY.md#%E6%8E%A8%E8%8D%90%E7%89%88%E6%9C%AC%E7%BB%84%E5%90%88).

```Python
python3 -c "import torch;import torch_npu; a = torch.randn(3, 4).npu(); print(a + a);"
```

Output similar to the following indicates a successful installation.

```text
tensor([[-0.6066,  6.3385,  0.0379,  3.3356],
        [ 2.9243,  3.3134, -1.5465,  0.1916],
        [-2.1807,  0.2008, -1.1431,  2.1523]], device='npu:0')
```
