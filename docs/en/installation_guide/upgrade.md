# Upgrade

1. You need to manually uninstall the old version first. For details, see [Uninstallation](uninstallation.md).
2. Install the new version. For details, see [Installing TorchNPU](installing_PyTorch.md).

> [!NOTE]
>
> - In a matching driver, firmware, and CANN software environment, you can upgrade the PyTorch framework and TorchNPU plugin separately.
> - If you also need to upgrade the firmware, driver, and CANN software, upgrade them in the order of "firmware → driver → CANN software" first, and then upgrade the PyTorch framework and TorchNPU plugin.
