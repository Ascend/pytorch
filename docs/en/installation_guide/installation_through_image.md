# Method 4: Installation Through Image

You can pull a Docker image with PyTorch and TorchNPU pre-installed to quickly build a running environment, without the need to install dependencies manually. For details, see [Quick Installation](https://www.hiascend.com/en-sg/developer/software/ai-frameworks/pytorch/download?versionId=183&ids=b1e62037594d4e5c9a0fd797ff490006%2C211%2C146%2C1%2C6%2C181%2Cd806).

> [!NOTE]
>
> - The method of installation through image supports only Python 3.12.
> - The image comes with the dependencies, such as ppyaml, numpy, attrs, decorator, psutil, scipy, jinja2, and MarkupSafe, pre-installed to support the running of related features.
