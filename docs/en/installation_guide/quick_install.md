### Environment Preparation

> [!NOTICE]
>
> You are advised to install and run programs as a non-root user and control the permissions of the installation directories and files: set the folder permissions to 750 and the file permissions to 640. You can control the permissions of installed files by setting umask, for example, setting umask to 0027. For more security-related content, see the "File Permission Control" descriptions of each component in [Security Statement](../reference/security_statement.md).

- Install the matching versions of the NPU driver and firmware and the CANN software (Toolkit, ops, and NNAL), and configure the CANN environment variables. For details, see [CANN Software Installation](https://www.hiascend.com/document/detail/en/CANNCommunityEdition/900/softwareinst/instg/instg_0000.html?OS=openEuler&InstallType=netyum).

    The CANN software provides a process-level environment variable setting script. Before using the NPU to execute business code in training or inference scenarios, you need to invoke this script; otherwise, the business code cannot be executed.

    ```bash
    source /usr/local/Ascend/cann/set_env.sh
    source /usr/local/Ascend/nnal/atb/set_env.sh
    ```

    The preceding commands take the default path after installation by the root user as an example. Replace the path with the actual path of set\_env.sh.

- Python 3.11 delivers better scheduling (that is, task dispatch) performance than Python 3.10. You are advised to use Python 3.11 or later.

## Post-Installation Verification

Run the following commands to check whether the PyTorch framework and TorchNPU plugin have been successfully installed.

```Python
python3 -c "import torch;import torch_npu; a = torch.randn(3, 4).npu(); print(a + a);"
```

If the output contains similar information, the installation is successful.

```text
tensor([[-0.6066,  6.3385,  0.0379,  3.3356],
        [ 2.9243,  3.3134, -1.5465,  0.1916],
        [-2.1807,  0.2008, -1.1431,  2.1523]], device='npu:0')
```

To view the installed Python, PyTorch, and TorchNPU versions in the current environment, see [Checking Versions](./references/check_installed_versions.md).

## Building from Source

For most users, it is recommended to install the PyTorch framework and TorchNPU plugin directly using the precompiled .whl packages to simplify the installation process and obtain a more stable experience. To perform feature tests, secondary development, or custom builds, see [Building from Source](./references/building_from_source.md) to compile from the source code and obtain the required .whl packages.

## Installing Extension Modules

For most users, installing the PyTorch framework and TorchNPU plugin meets the basic training and inference requirements. However, in specific development scenarios, you may also need to install corresponding extension modules. For example, to develop using the C++ interface, see [Building libtorch_npu](./references//building_libtorch_npu.md); to work on computer vision tasks, see [Installing torchvision](https://pytorch.org/get-started/locally/).
