# Method 3: Image Installation

Image installation is suitable for scenarios where you need to develop or use directly, without manually setting up the environment.

Before running the installation command, see [Pre-installation Preparation](preparing_installation.md) to configure environment variables and complete other environment preparations.

## Pulling Available Images

Pull images with pre-integrated TorchNPU packages and runtime dependencies from the Ascend image repository. Select the image based on your actual architecture.

## Running Docker

After pulling the image, you need to start the container with specific parameters to directly access Ascend devices.
