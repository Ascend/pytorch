# Method 3: Image Installation

Image installation is suitable for scenarios where you need to develop or use directly, without manually setting up the environment.

Before running the installation command, see the Pre-installation Preparation section in [Quick Installation](../quick_install.md) to complete the environment variable configuration and other environment preparations.

## Pulling Available Images

Pull images with pre-integrated TorchNPU packages and runtime dependencies from the Ascend image repository. Select the image based on your actual architecture.

## Running Docker

After pulling the image, you need to start the container with specific parameters so that you can directly access Ascend devices.
