# Error Information Analysis Description

During model training, users may encounter various error information, including Python call stacks and exception information, native framework error information, TorchNPU error codes, CANN software error codes, and plog logs. This section provides analysis guidance on locating the error source.

> [!NOTE]
>
> - Main principle for locating errors: pay attention to the first error message.
> - For details about errors related to the CANN software, see *[CANN Fault Handling](https://www.hiascend.com/document/detail/en/CANNCommunityEdition/910/maintenref/troubleshooting/troubleshooting_0001.html)*.
