# Security Statement

The security hardening measures listed in this topic are basic hardening recommendations. Users should re-examine the network security hardening measures of the entire system based on their own services. Users should perform related configurations according to the security policies of their organizations, including but not limited to software versions, system hardening requirements, security configurations (data storage, debugging interfaces, running environments, and so on), permission configurations, and firewall settings. When necessary, refer to excellent industry hardening solutions and the suggestions of security experts.
