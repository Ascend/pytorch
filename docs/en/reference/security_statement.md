# Security Statement

The security hardening measures listed in this document are basic hardening recommendations. You should re-examine the network security hardening measures of the entire system based on your own service requirements. You should make relevant configurations according to your organization's security policies, including but not limited to software versions, system hardening requirements, security configurations (data storage, debugging interfaces, runtime environments, and so on), permission configurations, and firewall settings. Where necessary, you can refer to excellent hardening solutions in the industry and advice from security experts.
