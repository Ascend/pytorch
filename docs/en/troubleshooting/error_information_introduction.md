# Error Information Introduction

You may encounter various error messages during model training, including Python call stacks and exception information, native framework error messages, TorchNPU error codes, CANN software error codes, and plogs. This section provides guidance on analyzing and locating the source of errors.

> [!NOTE]
>
> - The main principle for locating errors: focus on the first error message.
> - For detailed information on CANN software-related errors, see CANN Troubleshooting.
