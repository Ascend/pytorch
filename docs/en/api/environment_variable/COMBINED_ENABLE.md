# COMBINED\_ENABLE

## Function Description

This environment variable sets the combined flag. Setting it to 0 disables this feature, and setting it to 1 enables it to optimize scenarios in which two non-consecutive operators are combined.

The default configuration is 0.

## Configuration Example

```bash
export COMBINED_ENABLE=1
```

## Usage Constraints

None
