# INDUCTOR\_ASCEND\_AGGRESSIVE\_AUTOTUNE

## Function Description

Controls whether to enable the batch profiler, with a default value of "0".

- Default value "0": disables the batch profiler.
- Set to "1": enables the batch profiler.

## Configuration Example

```bash
export INDUCTOR_ASCEND_AGGRESSIVE_AUTOTUNE=1
```

## Usage Constraints

None
