# COMBINED\_ENABLE

## Function Description

This environment variable controls whether the combined contiguity optimization is enabled. When enabled, this feature optimizes the conversion of non-contiguous tensors generated by multiple view operations (for example, reshape+slice, permute+select, with up to 2 combined operations) by inferring the view information stack, avoiding a full memory copy.

- Configured as "0": disables this feature.
- Configured as "1": enables it.

The default configuration is "0".

This environment variable is provided by TorchNPU. PyTorch does not have a directly corresponding environment variable.

## Configuration Example

```bash
export COMBINED_ENABLE=1
```

## Usage Constraints

- This environment variable must be configured before the Python process starts. Changes made while the process is running do not take effect.
- Only "0" or "1" is supported.
- This environment variable takes effect only in the contiguity optimization on the aclop path. Operators using the aclnn path do not go through this optimization and are not affected by this environment variable.
