## Maintenance Policy

The maintenance phases of the TorchNPU version are as follows:

| Status            | Time                                                       | Description                                                                              |
| ----------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Planned           | 0--3 months before the first version release               | Planned features, pre-development                                                        |
| development       | 0 to 6 months after the first version release              | Develop new features, fix problems, and release new versions periodically.               |
| Maintenance       | Six to 12 months after the first release of the version    | Fix major bugs and add new features. Release patch versions based on the impact of bugs. |
| End of Life (EOL) | More than 12 months after the first release of the version | The version does not accept any modification.                                            |
